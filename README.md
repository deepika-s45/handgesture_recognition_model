# ✋ Hand Gesture Detection

## 📌 Overview

This project detects **hand gestures in real time** using a webcam.

The system uses computer vision and hand-tracking techniques to detect a user's hand and identify its position and movements through the webcam feed.

## 🛠️ Tools & Technologies

* Python
* OpenCV
* MediaPipe

## 🔄 Project Workflow

1. Access the webcam
2. Capture real-time video frames
3. Detect the hand using MediaPipe
4. Track hand landmarks
5. Process the detected hand
6. Display the results in real time

## 🎯 Objective

To develop a real-time computer vision application that can detect and track hand gestures using a webcam.

## ✨ Features

* Real-time webcam detection
* Hand landmark tracking
* Computer vision-based processing
* Real-time visualization

## 🚀 How to Run

1. Clone this repository.
2. Install the required libraries.
3. Run the Python program.
4. Allow webcam access when prompted.
5. Place your hand in front of the camera.
